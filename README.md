# Revolut-LP

This is a modern, responsive landing page inspired by **Revolut**. Designed with clean **HTML, CSS, and JavaScript**, this project focuses on a sleek UI/UX, interactive elements, and smooth animations.

## 🌟 Features
- Fully **responsive** design for all screen sizes
- **Smooth animations** and hover effects
- Well-structured **HTML & CSS** for easy customization
- **JavaScript interactivity** for dynamic elements
- Deployed on **GitHub Pages**: [Live Demo](https://surajkr97.github.io/Revolut-LP/)

## 🛠 How to Run
1. Clone the repo:
   ```sh
   git clone https://github.com/surajkr97/Revolut-LP.git
   ```
2. Open `index.html` in your browser to view the project.

## 📌 Technologies Used
- **HTML** for structure
- **CSS** for styling and responsiveness
- **JavaScript** for interactivity
